This project was made with the intention of being put into my [main portfolio site](https://blowupthenoobs.dev). With the following repo https://github.com/blowupthenoobs/PortfolioSite. It was put into a separate repo so that I could fulfill the WebOS stardance mission, but will likely be integrated into the main repo at some point, and thus who knows what will happen to this one (probably keep it up, won't really harm anything in any way to keep a reference to just the webOS.)
It's not super feature packed as of right now, but I've got a mockup of a terminal that you can type in (and nothing else,) as well as a diary window with a test entry written in. The idea is to make this fit more of an ARG type thing so the addition of being able to add notes and such is unlikely. I'll probably just make some sort of glitch effect for that.
For now though, the basic stuff is done, so it should be really easy to iterate on this for the WebOS 2 mission.

If you intend to run the project on your computer, after cloning the repo, make sure to cd into the webbingOS folder, then "npm install" to get the node modules. After the node modules are installed, run "npm run dev" to get the page up and running.
